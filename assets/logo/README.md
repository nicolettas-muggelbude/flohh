# flohh – Logo

Maskottchen nach einer Bleistiftskizze: ein geduckter, sprungbereiter Floh.

| Datei | Wofür |
| --- | --- |
| `flohh-logo.svg` | Bildzeichen + Wortmarke, für hellen Hintergrund |
| `flohh-logo-dark.svg` | Bildzeichen + Wortmarke, für dunklen Hintergrund |
| `flohh-mark.svg` | nur Bildzeichen, hell |
| `flohh-mark-dark.svg` | nur Bildzeichen, für dunklen Hintergrund |
| `flohh-mark-mono.svg` | nur Bildzeichen, einfarbig (Druck, Stempel) |
| `flohh-icon.svg` | App-Icon ab 48 px |
| `flohh-icon-small.svg` | App-Icon für 16–32 px (Favicon, Taskleiste) |
| `flohh.ico` | Windows-Icon (16–256 px) |
| `png/` | fertige PNGs, z. B. für README, Forum, Social Media |

Die Wortmarken-Dateien enthalten die Schrift als Pfade und sehen deshalb
überall gleich aus. Quelle sind die `flohh-mark*.svg`; nach Änderungen
`./scripts/build-logo.sh` laufen lassen.

## Farben

| Name | Wert | Einsatz |
| --- | --- | --- |
| Floh-Rot | `#E2552B` | Körper, Akzente |
| Tinte | `#1F1D1A` | Linien, Text, dunkler Grund |
| Papier | `#FFF8EF` | Kopf, helle Flächen |
| Grund | `#F6F3EC` | heller Seitenhintergrund, Text auf Dunkel |
| Grau | `#5E5A53` | gedämpfter Text |

## Schriften

- **Fredoka** SemiBold (600) – Wortmarke
- **DM Sans** – Oberfläche und Texte
